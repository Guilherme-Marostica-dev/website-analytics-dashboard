Website Performance & SEO Analytics Dashboard

**Live Demo:** https://website-analytics-dashboard.streamlit.app/

---

## Project Overview

This project analyzes website performance and SEO metrics to identify optimization opportunities and improve user experience.

It combines data analysis and visualization to answer a key business question:

> How do website performance and SEO impact user behavior?

---

## Objectives

- Analyze the relationship between **page load time**, **SEO score**, and **user engagement**
- Identify websites that require optimization
- Provide data-driven recommendations to improve performance and retention

---

## Tools & Technologies

- **Python (Pandas, Jupyter Notebook)**
- **Streamlit** (interactive dashboard)
- **Git & GitHub**

---

## Dataset

The dataset includes simulated website data with the following metrics:

- Load Time (seconds)
- SEO Score (0–100)
- Traffic (monthly visitors)
- Bounce Rate (%)

---

## Key Insights

- Websites with higher **load times** tend to have higher **bounce rates**, indicating performance directly impacts user retention  
- **SEO score** shows a strong relationship with **traffic**, reinforcing the importance of search optimization  
- Some websites can rank well despite poor performance, but still lose users due to slow loading  

---

## Features

- Interactive dashboard with filters  
- Website classification:
  - High Performer  
  - Average  
  - Needs Optimization  
- Visual analysis of performance vs user behavior
